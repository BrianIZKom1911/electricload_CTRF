This GitHub repo [electricload_CTRF](https://github.com/BrianIZKom1911/electricload_CTRF) is built for the submission and (possibly) publication purposes of my working paper. 
I may update it for convenience and controllability, but won't change the steps of data generation and analysis. If empirical work should be modified per the journal reviewers, there would be a new repo that absorbs all the modifications after everything is done .

The structure can be found in "project_structure.txt", which is generated by "print_projectstructure.py".

The code under "\script\S0_processdata" folder is used to process the raw data. The electricity and population data can be found in "\data_raw" folder. The weather station data (GHCN-h) is too large to store directly in the zip file or GitHub repo. Please download from Zenodo and place in this folder "\data_raw\GHCNh_Texas".

https://doi.org/10.5281/zenodo.15996334
Please refer to the introduction there for the necessary information.
