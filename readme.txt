# Purpose 
This GitHub repo [electricload_CTRF](https://github.com/BrianIZKom1911/electricload_CTRF) is built for publication purpose of my working paper. I may update it for user convenience and controllability, but won't change the basic logic of data generation, analysis, and visualization. If I receive advice from the Journal's editors/reviewers, I might modify existing files and add new folders for supplementary results.

- (Dec 2025) During revision, I added "\script\S3_supplement" which contains code to produce more figures. Part of the results characterize the variables' distributions, and the others  complement CTRF graphs for more regions and hours which are eventually compressed into GIFs.

# Structure
The structure can be found in "project_structure.txt", which is generated by "print_projectstructure.py".

# Data
The code under "\script\S0_processdata" folder is used to process the raw data. The electricity and population data can be found in "\data_raw" folder. The weather station data (GHCN-h) is too large to store directly in the zip file or GitHub repo. Please download from Zenodo and place in this folder "\data_raw\GHCNh_Texas".

Zenodo DOI:
https://doi.org/10.5281/zenodo.15996334
Please refer to the introduction there for necessary information.
